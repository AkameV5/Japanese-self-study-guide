Самоучитель японского языка 🇯🇵
Ver 2.2 - Исправлена возможность добавления фотографий и их синхронизация на устройствах, а также изменение хранения аудио в папке audio проекта
Мобильное приложение для Android, предназначенное для эффективного и структурированного изучения основ японского языка.

Основные возможности:
Изучение азбук: интерактивные таблицы Хираганы и Катаканы с упражнениями.
Кандзи и Словарь: база иероглифов с уровнями JLPT и удобный поиск по словам.
Адаптированные тексты: библиотека рассказов для практики чтения.
Аудирование: встроенный плеер с регулировкой скорости для работы над произношением.
Прогресс: визуальное отслеживание успехов (индикаторы в виде лепестков сакуры).

Технологии
Язык: Java (Android Studio)
Backend: Firebase
Архитектура: клиент-серверная модель.

Как запустить
1. Склонируйте проект: `git clone https://github.com/AkameV5/Japanese-self-study-guide.git`
2. Откройте проект в Android Studio (версия Electric Eel или выше).
3. Дождитесь синхронизации Gradle и запустите приложение на эмуляторе или реальном устройстве.
4. Обновление базы данных: в директории `app/src/main/res/raw` находятся исходные файлы данных (JSON). Вы можете редактировать эти файлы для изменения списка слов, иероглифов или грамматических правил.
При запуске соответствующих методов синхронизации в приложении ( `app/src/main/java/com/example/japanese_self_study_guide/DB.java)`, данные автоматически обновляются в облачной базе данных (Firebase).
